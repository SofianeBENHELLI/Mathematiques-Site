PREMIÈRE SPÉCIALITÉ · SUITES

Une règle, et la suite se déroule.

Tu vas apprendre à reconnaître une suite arithmétique ou géométrique, à calculer ses termes et ses sommes, à prévoir son comportement et à trouver le moment où elle dépasse un seuil.

TON PARCOURSGénérer → reconnaître → sommer → varier → seuil → modéliser

Chaque idée a son atelier : manipule d'abord, retiens ensuite.

01 / L'ESSENTIEL

Sept idées à posséder.

▤ 1. Générer une suite : explicite ou par récurrence+

Une suite (uₙ) associe à chaque entier n un réel uₙ. Deux façons de la définir :

Explicite : uₙ = f(n)   (on calcule uₙ directement)
Récurrence : u₀ donné et uₙ₊₁ = f(uₙ)   (il faut passer par tous les termes précédents)

Exemples : uₙ = n² − 3 donne u₄ = 13 d'un coup. u₀ = 2 et uₙ₊₁ = 3uₙ − 1 donne u₁ = 5, u₂ = 14, u₃ = 41 : on ne saute pas d'étape. Les termes se calculent à la main, au tableur ou en Python (atelier 5).

Piège. uₙ₊₁ n'est pas uₙ + 1, c'est le terme suivant. Et u₂ₙ n'est pas 2uₙ.

▤ 2. Suite arithmétique : on ajoute toujours la même chose+

uₙ₊₁ = uₙ + r    uₙ = u₀ + n·r    uₙ = uₚ + (n − p)·r

r est la raison. Pour reconnaître une suite arithmétique : montrer que uₙ₊₁ − uₙ est le même nombre pour tout n. Graphiquement, les points (n ; uₙ) sont alignés sur une droite de pente r : croissante si r > 0, décroissante si r < 0, constante si r = 0.

▤ 3. Suite géométrique : on multiplie toujours par la même chose+

uₙ₊₁ = q·uₙ    uₙ = u₀·qⁿ    uₙ = uₚ·qⁿ⁻ᵖ

q est la raison. Pour reconnaître : montrer que uₙ₊₁/uₙ est constant (en vérifiant que uₙ ≠ 0). Si u₀ > 0 : croissante pour q > 1, décroissante pour 0 < q < 1, et alternée (signes + − + −) pour q < 0.

Lien avec l'exponentielle : (eᵃⁿ) est géométrique de raison eᵃ. C'est la même croissance, en pas entiers.

▤ 4. Sommes de termes consécutifs (démonstrations exigibles)+

1 + 2 + … + n = n(n + 1)/2
1 + q + q² + … + qⁿ = (1 − qⁿ⁺¹)/(1 − q)   (q ≠ 1)

Démonstration de la première. Écris S = 1 + 2 + … + n puis S = n + (n − 1) + … + 1. En additionnant colonne par colonne, chaque somme vaut n + 1 et il y a n colonnes : 2S = n(n + 1).

Démonstration de la seconde. Posons S = 1 + q + … + qⁿ. Alors qS = q + q² + … + qⁿ⁺¹. En soustrayant, S − qS = 1 − qⁿ⁺¹, donc S(1 − q) = 1 − qⁿ⁺¹.

Somme arithmétique : nombre de termes × (premier + dernier)/2. Somme géométrique : premier terme × (1 − qᶰᵒᵐᵇʳᵉ ᵈᵉ ᵗᵉʳᵐᵉˢ)/(1 − q).

Piège. De u₀ à uₙ, il y a n + 1 termes, pas n.

▤ 5. Variations et comportement+

(uₙ) croissante ⇔ uₙ₊₁ − uₙ ≥ 0 pour tout n
Si uₙ > 0 : croissante ⇔ uₙ₊₁/uₙ ≥ 1

On étudie le signe de uₙ₊₁ − uₙ. Pour une suite explicite uₙ = f(n), on peut aussi étudier les variations de f, mais la réciproque est fausse : la suite peut croître sans que f soit monotone.

Conjecturer le comportement : arithmétique de raison r > 0 : tend vers +∞ ; géométrique de raison q > 1 et u₀ > 0 : tend vers +∞ ; avec 0 < q < 1 : se rapproche de 0 ; avec q ≤ −1 : n'a pas de limite, elle oscille.

▤ 6. Seuil et algorithme+

Chercher le plus petit n tel que uₙ dépasse un seuil S, c'est exécuter une boucle while :

n = 0 ; u = u0
while u <= S :
    u = q * u    (ou u + r)
    n = n + 1
(à la sortie, n est le plus petit indice tel que u > S)

Pour une suite croissante, dès que le seuil est franchi il le reste. On peut aussi résoudre l'inéquation u₀·qⁿ > S par essais, avec la calculatrice.

▤ 7. Modéliser une évolution+

Variation à pas constant (on ajoute 15 € par mois) : suite arithmétique. Variation à taux constant (+3 % par an) : suite géométrique de raison q = 1 + t/100. Une baisse de 20 % donne q = 0,8.

Attention : deux hausses successives de 10 % ne font pas 20 % mais 1,1 × 1,1 = 1,21, soit +21 %. Une hausse de 50 % suivie d'une baisse de 50 % donne 1,5 × 0,5 = 0,75 : −25 %.
