PREMIÈRE SPÉCIALITÉ · GÉOMÉTRIE REPÉRÉE

Une équation, une droite ou un cercle.

Tu vas passer sans hésiter d’une droite à son équation et inversement, trouver intersections et tangentes, et utiliser le vecteur normal pour tout ramener à un produit scalaire.

01 / L'ESSENTIEL

Cinq idées à posséder.

▤ 1. Équations d’une droite+

Réduite : y = mx + p (m = pente, p = ordonnée à l'origine)
Cartésienne : ax + by + c = 0 avec (a ; b) ≠ (0 ; 0)
Verticale : x = k

La pente passant par A(xA ; yA) et B(xB ; yB) est m = (yB − yA)/(xB − xA) si xA ≠ xB. On trouve p en remplaçant un point.

Un vecteur directeur de ax + by + c = 0 est u(−b ; a). Un vecteur normal est n(a ; b). Ils sont orthogonaux : (−b)a + a·b = 0.

▤ 2. Colinéarité, parallélisme, alignement+

u(x ; y) et v(x′ ; y′) colinéaires ⇔ xy′ − x′y = 0

Trois points A, B, C sont alignés si AB et AC sont colinéaires. Deux droites sont parallèles si leurs vecteurs directeurs sont colinéaires (même pente).

Pour trouver le point d'intersection de deux droites sécantes, on résout le système formé par leurs deux équations. Sans solution : parallèles distinctes. Une infinité : droites confondues.

▤ 3. Droite définie par un vecteur normal+

La droite passant par A et de vecteur normal n(a ; b) est l'ensemble des points M tels que AM·n = 0. En coordonnées : a(x − xA) + b(y − yA) = 0, soit ax + by + c = 0 avec c = −(a·xA + b·yA).

Exemple : A(2 ; 1), n(3 ; 4) donne 3(x − 2) + 4(y − 1) = 0, soit 3x + 4y − 10 = 0.

Une parallèle à ax + by + c = 0 garde les mêmes a et b, seul c change. Une perpendiculaire a pour normal le vecteur directeur de l'autre.

▤ 4. Équation d’un cercle+

Le cercle de centre Ω(p ; q) et de rayon r est l'ensemble des points M tels que ΩM = r :

(x − p)² + (y − q)² = r²    soit    x² + y² − 2px − 2qy + (p² + q² − r²) = 0

Réciproquement, pour reconnaître x² + y² + ux + vy + w = 0, on écrit la forme canonique : (x + u/2)² + (y + v/2)² = u²/4 + v²/4 − w. Si le second membre est positif : cercle ; nul : un point ; négatif : ensemble vide.

Piège. Le centre a des coordonnées opposées à celles de la parenthèse : (x + 1)² donne p = −1.

▤ 5. Tangente et position relative+

Une droite d et un cercle de centre Ω et de rayon r : soit δ la distance de Ω à d. Si δ < r : deux points communs ; δ = r : tangente (un point) ; δ > r : aucun point.

La tangente au cercle en un point A du cercle est la droite passant par A et de vecteur normal ΩA : c'est l'ensemble des M tels que ΩA·AM = 0.

Distance d'un point P(x₀ ; y₀) à la droite ax + by + c = 0 : δ = |ax₀ + by₀ + c|/√(a² + b²).

Ensembles de points. MA·u = k est une droite de vecteur normal u. MA·MB = 0 est le cercle de diamètre [AB].
