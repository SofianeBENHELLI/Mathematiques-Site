Résumer le hasard par deux nombres.

01 / L'ESSENTIEL

Cinq idées à posséder.

▤ 1. Loi d’une variable aléatoire discrète+

Une variable aléatoire X associe un nombre à chaque issue. Sa loi est la liste des probabilités P(X = xᵢ) = pᵢ. Elles sont positives et leur somme vaut 1.

Exemple : X = gain d'un jeu. Pour trouver une probabilité manquante, on utilise Σpᵢ = 1.

▤ 2. Espérance, variance, écart type+

E(X) = x₁p₁ + x₂p₂ + …    V(X) = Σ pᵢ(xᵢ − E(X))²    σ(X) = √V(X)

L'espérance est la moyenne des valeurs pondérée par les probabilités : ce qu'on obtient « en moyenne » sur un grand nombre de répétitions. La variance mesure la dispersion autour de cette moyenne, l'écart type la ramène à l'unité de X.

Pour un jeu : si E(gain net) = 0 le jeu est équitable, > 0 favorable, < 0 défavorable.

▤ 3. Linéarité et formule de König-Huygens+

E(aX + b) = aE(X) + b    V(aX + b) = a²V(X)    σ(aX + b) = |a|σ(X)
V(X) = E(X²) − (E(X))²

Démonstration de E(aX + b). Σ(axᵢ + b)pᵢ = aΣxᵢpᵢ + bΣpᵢ = aE(X) + b×1.

Démonstration de König-Huygens. V(X) = Σpᵢ(xᵢ − m)² = Σpᵢxᵢ² − 2mΣpᵢxᵢ + m²Σpᵢ = E(X²) − 2m² + m² = E(X²) − m².

Ajouter une constante b décale la moyenne, ne change pas la dispersion. Multiplier par a multiplie l'écart type par |a|.

▤ 4. Épreuve de Bernoulli et schéma de Bernoulli+

Une épreuve de Bernoulli a deux issues : succès (probabilité p) et échec (probabilité 1 − p). Un schéma de Bernoulli répète n fois la même épreuve de façon indépendante.

Sur l'arbre du schéma à 3 épreuves, la probabilité d'un chemin à k succès est pᵏ(1 − p)ⁿ⁻ᵏ. Il y a C(n,k) chemins à k succès, qu'on compte sur l'arbre ou avec la calculatrice.

▤ 5. Loi binomiale B(n ; p)+

X = nombre de succès dans un schéma de Bernoulli de n épreuves de paramètre p suit la loi binomiale B(n ; p).

P(X = k) = C(n,k) pᵏ (1 − p)ⁿ⁻ᵏ    E(X) = np    V(X) = np(1 − p)

Exemple : B(4 ; 0,5), P(X = 2) = 6 × 0,5⁴ = 0,375. Pour « au moins un succès » on passe par l'événement contraire : P(X ≥ 1) = 1 − P(X = 0) = 1 − (1 − p)ⁿ.

Piège. Les épreuves doivent être identiques et indépendantes : tirer sans remise dans une petite urne ne donne pas une loi binomiale.
