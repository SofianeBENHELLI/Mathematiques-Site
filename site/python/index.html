01 / L'ESSENTIEL

Sept idées à posséder.

▤ 1. Variables et affectation+

Une variable porte un nom et une valeur. L'instruction x = 3 range la valeur 3 dans x. L'affectation se lit de droite à gauche : x = x + 1 calcule x + 1 avec l'ancienne valeur, puis range le résultat dans x.

x = 3
y = 2 * x    # y vaut 6
x = y + 1    # x vaut 7, y vaut toujours 6

Une opération comme / donne un nombre à virgule (7/2 vaut 3.5), // donne le quotient entier (7 // 2 vaut 3) et % le reste (7 % 2 vaut 1).

▤ 2. Conditions : if, elif, else+

if x % 2 == 0:
    y = x / 2
else:
    y = 3 * x + 1

La condition est vraie ou fausse. == teste l'égalité, = affecte. Les opérateurs de comparaison : ==, !=, <, <=, >, >=, et on les combine avec and, or, not. L'indentation (4 espaces) délimite le bloc.

▤ 3. Boucles for et while+

for répète un nombre de fois connu : for i in range(n) prend i = 0, 1, …, n − 1 (n tours, la borne n est exclue). range(a, b) va de a à b − 1, range(a, b, pas) avance par pas.

s = 0
for i in range(1, 5):
    s = s + i
print(s)    # 1 + 2 + 3 + 4 = 10

while répète tant qu'une condition est vraie, quand on ne connaît pas le nombre de tours. Il faut que quelque chose dans la boucle fasse changer la condition, sinon la boucle ne s'arrête jamais.

▤ 4. Fonctions+

def f(x):
    return x * x - 3

print(f(2))    # 1
print(f(f(2)))    # f(1) = -2

Une fonction reçoit des paramètres et renvoie un résultat avec return. Elle permet de réutiliser un calcul et de le tester sur plusieurs valeurs. print affiche, return renvoie : ce n'est pas la même chose.

▤ 5. Listes+

L = [3, 8, 1]
L.append(5)    # [3, 8, 1, 5]
len(L)    # 4
L[0]    # 3 (le premier a l'indice 0)
[x * x for x in range(5)]    # [0, 1, 4, 9, 16]
[x for x in range(20) if x % 3 == 0]    # 7 éléments

On parcourt une liste avec for x in L. Les indices commencent à 0 : le dernier élément d'une liste de n éléments a pour indice n − 1 (ou −1).

▤ 6. Suites et seuils+

u = 100    n = 0
while u > 50:
    u = 0.9 * u
    n = n + 1
print(n)    # premier rang où u ≤ 50

Pour calculer un terme : une boucle for. Pour chercher le premier rang qui dépasse un seuil : une boucle while avec un compteur n. Le test de la boucle est la négation de ce qu'on cherche : on continue tant que le seuil n'est pas atteint.

▤ 7. Dichotomie et simulation+

Dichotomie. Pour encadrer une solution de f(x) = 0 sur [a ; b] quand f est continue et change de signe : on coupe en m = (a + b)/2 et on garde la moitié où le signe change. Chaque tour divise la largeur par 2.

while b - a > 0.001:
    m = (a + b) / 2
    if f(a) * f(m) <= 0:
        b = m
    else:
        a = m

Simulation. from random import randint, random : randint(1, 6) donne un entier de 1 à 6 inclus, random() un réel de [0 ; 1[. On simule beaucoup d'expériences et on observe la fréquence : elle se rapproche de la probabilité.
