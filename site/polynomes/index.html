01 / L'ESSENTIEL

Six idées à posséder.

▤ 1. Les trois formes d’un trinôme+

Développée : f(x) = ax² + bx + c   (a ≠ 0)
Canonique : f(x) = a(x − α)² + β   avec α = −b/(2a) et β = f(α)
Factorisée : f(x) = a(x − x₁)(x − x₂)   (si des racines existent)

Chaque forme répond à une question : la développée donne f(0) = c ; la canonique donne le sommet S(α ; β) et les variations ; la factorisée donne les racines et le signe.

Passer de la canonique à la développée : on développe. De la développée à la canonique : α = −b/(2a), β = f(α). Exemple : x² − 6x + 5, α = 3, β = 9 − 18 + 5 = −4, donc (x − 3)² − 4.

▤ 2. Discriminant et racines+

Δ = b² − 4ac
Δ > 0 : deux racines x = (−b ± √Δ)/(2a)
Δ = 0 : une racine double x = −b/(2a)
Δ < 0 : aucune racine réelle

D'où vient Δ ? En mettant a(x + b/(2a))² − Δ/(4a) sous forme canonique, l'équation devient (x + b/(2a))² = Δ/(4a²). Un carré ne peut valoir qu'un nombre positif ou nul : c'est le signe de Δ qui décide.

Piège. Δ se calcule avec les signes de b et c : pour 2x² − 3x − 2, Δ = (−3)² − 4×2×(−2) = 9 + 16 = 25. Et −b/(2a) quand b est négatif devient positif.

▤ 3. Signe du trinôme et inéquations+

Δ > 0 : signe de a à l'extérieur des racines, signe de −a entre les racines
Δ = 0 : signe de a partout, sauf en la racine double (0)
Δ < 0 : signe de a partout

Méthode : 1. calculer Δ et les racines ; 2. dessiner la parabole (a > 0 : en U, a < 0 : en ∩) ; 3. lire où la courbe est au-dessus ou au-dessous de l'axe ; 4. écrire l'ensemble solution avec les crochets qui conviennent (fermés pour ≤ et ≥, ouverts pour < et >).

▤ 4. Parabole : axe, sommet, variations+

La courbe de f est une parabole d'axe de symétrie x = α = −b/(2a) et de sommet S(α ; β).

a > 0 : décroissante sur ]−∞ ; α], croissante sur [α ; +∞[, minimum β
a < 0 : croissante sur ]−∞ ; α], décroissante sur [α ; +∞[, maximum β

Si les racines existent, α est leur milieu : α = (x₁ + x₂)/2. C'est utile pour optimiser (aire maximale, bénéfice maximal).

▤ 5. Somme et produit des racines+

x₁ + x₂ = −b/a    x₁ × x₂ = c/a

Démonstration. a(x − x₁)(x − x₂) = ax² − a(x₁ + x₂)x + a·x₁x₂. Par identification avec ax² + bx + c : b = −a(x₁ + x₂) et c = a·x₁x₂.

Usages : trouver la seconde racine quand l'une est connue (ou évidente), ou construire un trinôme de racines données. Pour deux nombres de somme S et de produit P : ce sont les racines de x² − Sx + P.

▤ 6. Changement d’inconnue+

Une équation comme x⁴ − 5x² + 4 = 0 se ramène au second degré en posant X = x². On résout X² − 5X + 4 = 0, soit X = 1 ou X = 4.

Puis on revient à x : x² = 1 donne x = ±1, x² = 4 donne x = ±2. Quatre solutions. Si X < 0, x² = X n'a pas de solution ; si X = 0, une seule (x = 0).

Piège. Oublier de revenir à x, ou accepter une valeur négative de X = x².
