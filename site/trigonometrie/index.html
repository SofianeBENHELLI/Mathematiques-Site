Un point qui tourne, deux courbes qui naissent.

Tu vas lire cos et sin directement sur le cercle, retrouver les valeurs remarquables sans les apprendre par cœur, et résoudre les équations en les voyant.

01 / L'ESSENTIEL

Six idées à posséder.

▤ 1. Le radian et le cercle trigonométrique+

π rad = 180°    α° = α × π/180 rad

Le cercle trigonométrique est le cercle de centre O et de rayon 1, orienté dans le sens direct (inverse des aiguilles d'une montre). Un angle de x radians correspond à un arc de longueur x sur ce cercle : c'est pour cela que le radian est l'unité naturelle. Le point image M de x a pour coordonnées (cos x ; sin x).

Deux réels qui diffèrent d'un multiple de 2π ont le même point image : x et x + 2kπ (k entier). La mesure principale est celle qui est dans ]−π ; π].

▤ 2. Valeurs remarquables+
x0π/6π/4π/3π/2π
cos x1√3/2√2/21/20−1
sin x01/2√2/2√3/210

Truc pour ne rien apprendre : sin x vaut √0/2, √1/2, √2/2, √3/2, √4/2 pour x = 0, π/6, π/4, π/3, π/2. Pour cos, on lit la même liste à l'envers.

▤ 3. Relations fondamentales+

cos² x + sin² x = 1    −1 ≤ cos x ≤ 1    −1 ≤ sin x ≤ 1

Elle vient du théorème de Pythagore dans le triangle rectangle formé par M, son projeté sur (Ox) et O, de côtés |cos x| et |sin x| et d'hypoténuse 1. Si l'on connaît cos x et le signe de sin x, on retrouve sin x.

Piège. sin² x signifie (sin x)², pas sin(x²). Et sin x = ±√(1 − cos² x) : le signe se lit sur le cercle.

▤ 4. Symétries et périodicité+

cos(−x) = cos x   sin(−x) = −sin x
cos(π − x) = −cos x   sin(π − x) = sin x
cos(π + x) = −cos x   sin(π + x) = −sin x
cos(π/2 − x) = sin x   sin(π/2 − x) = cos x
cos(x + 2π) = cos x   sin(x + 2π) = sin x

Ne retiens pas cette liste : vois la symétrie du point M. −x : par rapport à (Ox). π − x : par rapport à (Oy). π + x : par rapport à O. π/2 − x : par rapport à la première bissectrice. L'atelier 3 les montre toutes.

▤ 5. Les courbes de cos et de sin+

Les courbes de cos et sin sont des sinusoïdes, de période 2π, comprises entre −1 et 1. cos est paire (symétrique par rapport à l'axe des ordonnées), sin est impaire (symétrique par rapport à O). Elles se déduisent l'une de l'autre par une translation : sin x = cos(x − π/2).

Pour a·cos(bx + c) + d : amplitude |a|, période 2π/|b|, décalage horizontal −c/b, axe médian y = d. Atelier 4.

▤ 6. Résoudre cos x = a et sin x = a+

cos x = cos α ⇔ x = α + 2kπ ou x = −α + 2kπ
sin x = sin α ⇔ x = α + 2kπ ou x = π − α + 2kπ

Méthode : on place la valeur a sur l'axe qui convient (abscisses pour cos, ordonnées pour sin), on trace la droite, on lit les deux points du cercle, puis on garde ceux de l'intervalle demandé. Atelier 5.

Pour aller plus loin. cos′ = −sin et sin′ = cos, donc (cos(ax + b))′ = −a·sin(ax + b) et (sin(ax + b))′ = a·cos(ax + b).
