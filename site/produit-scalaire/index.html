Un seul nombre, trois façons de le calculer.

01 / L'ESSENTIEL

Cinq idées à posséder.

▤ 1. Trois définitions du même nombre+

Avec les coordonnées : u(x ; y) et v(x′ ; y′) donnent u·v = xx′ + yy′
Avec l'angle : u·v = ‖u‖ × ‖v‖ × cos θ (θ = angle entre u et v)
Avec la projection : u·v = AB × AH (mesure algébrique) où H est le projeté orthogonal de C sur (AB), pour u = AB et v = AC

Le résultat est un nombre, pas un vecteur. Il est positif si l'angle est aigu, négatif s'il est obtus, nul si les vecteurs sont orthogonaux.

Choisir la bonne formule : coordonnées connues → la première ; longueurs et angle connus → la deuxième ; figure avec un angle droit → la troisième.

▤ 2. Orthogonalité+

u ⊥ v ⇔ u·v = 0

Pour deux vecteurs non nuls, u·v = ‖u‖‖v‖cos θ est nul si et seulement si cos θ = 0, c'est-à-dire θ = 90°. Avec les coordonnées : (3 ; 2) et (−2 ; 3) sont orthogonaux car 3×(−2) + 2×3 = 0.

Méthode. Pour prouver que deux droites (AB) et (CD) sont perpendiculaires : calculer AB·CD avec les coordonnées et trouver 0. Pour un triangle rectangle en A : AB·AC = 0.

Piège. Ne pas confondre u·v = 0 (orthogonal) avec « u et v colinéaires » (qui se teste avec xy′ − x′y = 0).

▤ 3. Propriétés et identités remarquables+

u·v = v·u    u·(v + w) = u·v + u·w    (ku)·v = k(u·v)
u·u = ‖u‖² (on le note u²)
‖u + v‖² = ‖u‖² + 2u·v + ‖v‖²
‖u − v‖² = ‖u‖² − 2u·v + ‖v‖²
u·v = ½(‖u + v‖² − ‖u‖² − ‖v‖²)

Elles se démontrent en développant avec la bilinéarité, comme (a + b)² en algèbre. Elles permettent de calculer u·v quand on connaît les trois longueurs d'un triangle, sans coordonnées.

▤ 4. Longueurs et angles : théorème d’Al-Kashi+

Dans un triangle ABC de côtés a = BC, b = AC, c = AB :
a² = b² + c² − 2bc cos Â

Démonstration. BC² = ‖AC − AB‖² = AC² + AB² − 2 AB·AC = b² + c² − 2bc cos Â.

Si Â = 90°, cos Â = 0 : on retrouve le théorème de Pythagore. Al-Kashi permet de trouver un côté (deux côtés et l'angle compris) ou un angle (trois côtés) : cos Â = (b² + c² − a²)/(2bc).

Pour un angle avec les coordonnées : cos(AB, AC) = AB·AC / (AB × AC).

▤ 5. Projection orthogonale+

Le projeté orthogonal de C sur la droite (AB) est le point H de (AB) tel que (CH) ⊥ (AB). Alors AB·AC = AB·AH.

Si H est du même côté de A que B : le produit est positif et vaut AB × AH. Si H est du côté opposé : il est négatif et vaut −AB × AH.

Cette formule évite de calculer l'angle : utile dans un rectangle, un carré ou un triangle isocèle où les projetés sont des milieux ou des sommets.
